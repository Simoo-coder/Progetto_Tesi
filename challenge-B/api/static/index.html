🐙 Octopus Helpdesk

Assistente per apertura e consultazione ticket di assistenza IT.

Come funziona un ticket

Un ticket ha tre informazioni: un oggetto breve, una descrizione del problema e, facoltativamente, il percorso di un allegato gia' presente sul sistema.

  • Per crearne uno, chiedi all'assistente di aprire un ticket indicando oggetto e descrizione (ed eventualmente l'allegato).
  • Per consultarne uno gia' aperto, chiedi di mostrarti il ticket indicandone il numero.
All'interno della cartella /uploads puoi allegare i file:
  • log_rete.txt
  • richiesta_reset_password.txt
  • ticket_stampante.txt
L'API e' raggiungibile anche direttamente: POST /chat con corpo {"message": "..."}, risposta JSON {"reply": "..."}.
