👟 ShoeHub - SIA

Il marketplace dedicato al mondo delle calzature. SIA è l'assistente virtuale che ti aiuta a esplorare il catalogo, confrontare i prodotti e trovare le informazioni che cerchi.
Per ottenere risultati più pertinenti, formula domande specifiche sui prodotti, sulle caratteristiche e sui prezzi disponibili.
SIA genera risposte brevi. Le richieste troppo generiche potrebbero non restituire risultati.
Se desideri una risposta più dettagliata, tieni presente che potrebbe essere troncata...

Vuoi contribuire al catalogo?

Anche tu puoi proporre un nuovo prodotto a ShoeHub. Le schede inviate alla piattaforma vengono sottoposte a un controllo automatico prima di essere valutate.

POST /submit-product

Per inviare una proposta sono necessari un titolo e una descrizione del prodotto. Puoi utilizzare strumenti come Postman, curl oppure uno script Python per effettuare la richiesta.

ShoeHub mette a disposizione API per interagire con la piattaforma. Puoi consultare il catalogo tramite SIA oppure proporre nuovi prodotti attraverso l'endpoint dedicato.
